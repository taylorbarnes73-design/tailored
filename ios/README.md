## Tailored By Taylor iOS

This folder contains a native SwiftUI version of the Tailored by Taylor experience.

What is included:
- A native `TabView` app shell for Shop, Style Lab, and Profile
- Preference-aware fit scoring inspired by the Smart-Fit integration
- Imported "Studio Drop" catalog items modeled after the IDM-VTON repo
- Profile editing and fit intelligence cards in SwiftUI

Open `TailoredByTaylor.xcodeproj` in Xcode and run the `TailoredByTaylor` scheme on an iPhone simulator.

Notes:
- This machine currently does not have a full Xcode toolchain enabled, so the project could not be simulator-built in this session.
- The project uses iOS 17+ APIs and the Observation framework.
